## 🎯 命名规范

### 文件夹命名
```
格式: [三位编号]-[中文名称]-[英文名称]
示例: 001-二分查找-BinarySearch
```

### 文件命名
- **Solution.cs** - 解题代码（统一使用此名称）
- **README.md** - 题目说明和解题思路
- **Tests.cs** - 单元测试（待添加）

### 类命名
```
格式: [英文名称]_Solution
示例: BinarySearch_Solution, MoveZero_Solution
```

## 📝 使用指南

### 1. 运行演示
```bash
dotnet run
```
默认运行前两道题的测试用例，可在 Program.cs 中取消注释以测试其他题目。

### 2. 查看题目
打开 `算法分类/[分类]/[题目]/README.md` 查看题目描述和解题思路。

### 3. 查看代码
打开 `算法分类/[分类]/[题目]/Solution.cs` 查看完整实现。

### 4. 添加新题
1. 确定算法分类（数组/链表/动态规划等）
2. 在对应分类下创建新文件夹：`XXX-题目名-EnglishName`
3. 创建 `Solution.cs` 和 `README.md`
4. 更新根目录的 `README.md` 添加题目链接

## 💡 最佳实践

### 每道题的标准结构
```
题目文件夹/
├── Solution.cs          # 必须：解题代码
├── README.md           # 必须：题目说明
└── Tests.cs            # 可选：单元测试
```

### Solution.cs 模板
```csharp
namespace _2026offerTest.算法分类.[分类];

/// <summary>
/// [题目名称]
/// 难度: [简单/中等/困难]
/// 标签: [标签1, 标签2]
/// </summary>
public class [Name]_Solution
{
    /// <summary>
    /// [方法说明]
    /// 时间复杂度: O(...)
    /// 空间复杂度: O(...)
    /// </summary>
    public [ReturnType] [MethodName](...)
    {
        // 实现代码
    }
}
```

### README.md 模板
- 题目描述
- 示例
- 解题思路
- 复杂度分析
- 关键点
- 相关题目
