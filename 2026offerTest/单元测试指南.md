# 单元测试指南（可选）

## 📦 如何添加单元测试

### 方案一：在当前项目中添加测试类（简单）

在每道题的文件夹中创建 `Tests.cs` 文件：

```csharp
namespace _2026offerTest.算法分类._01_数组;

public class BinarySearch_Tests
{
    public static void RunTests()
    {
        var solution = new BinarySearch_Solution();
        
        // 测试用例 1
        int[] nums1 = { -1, 0, 3, 5, 9, 12 };
        int result1 = solution.Search(nums1, 9);
        Console.WriteLine($"测试1: {(result1 == 4 ? "✅ 通过" : "❌ 失败")} (期望: 4, 实际: {result1})");
        
        // 测试用例 2
        int result2 = solution.Search(nums1, 2);
        Console.WriteLine($"测试2: {(result2 == -1 ? "✅ 通过" : "❌ 失败")} (期望: -1, 实际: {result2})");
    }
}
```

然后在 `Program.cs` 中调用：
```csharp
BinarySearch_Tests.RunTests();
```

### 方案二：创建独立的测试项目（推荐）

#### 1. 创建 xUnit 测试项目
```bash
cd E:\RiderProjects\2026offerTest
dotnet new xunit -n AlgorithmTests
dotnet add AlgorithmTests reference 2026offerTest/2026offerTest.csproj
```

#### 2. 示例测试文件
```csharp
using Xunit;
using _2026offerTest.算法分类._01_数组;

namespace AlgorithmTests
{
    public class BinarySearchTests
    {
        private readonly BinarySearch_Solution _solution;

        public BinarySearchTests()
        {
            _solution = new BinarySearch_Solution();
        }

        [Fact]
        public void Search_TargetExists_ReturnsCorrectIndex()
        {
            // Arrange
            int[] nums = { -1, 0, 3, 5, 9, 12 };
            
            // Act
            int result = _solution.Search(nums, 9);
            
            // Assert
            Assert.Equal(4, result);
        }

        [Fact]
        public void Search_TargetNotExists_ReturnsMinusOne()
        {
            // Arrange
            int[] nums = { -1, 0, 3, 5, 9, 12 };
            
            // Act
            int result = _solution.Search(nums, 2);
            
            // Assert
            Assert.Equal(-1, result);
        }

        [Fact]
        public void Search_EmptyArray_ReturnsMinusOne()
        {
            // Arrange
            int[] nums = { };
            
            // Act
            int result = _solution.Search(nums, 1);
            
            // Assert
            Assert.Equal(-1, result);
        }
    }
}
```

#### 3. 运行测试
```bash
cd AlgorithmTests
dotnet test
```

## ✅ 测试覆盖建议

### 必须测试的场景
1. **正常情况** - 典型输入和预期输出
2. **边界条件** - 空数组、单元素、最大值、最小值
3. **异常情况** - null 输入、无效参数

### 示例：移动零的完整测试
```csharp
public class MoveZero_Tests
{
    [Fact]
    public void MoveZeroes_NormalCase_Works()
    {
        var solution = new MoveZero_Solution();
        int[] nums = { 0, 1, 0, 3, 12 };
        
        solution.MoveZeroes(nums);
        
        Assert.Equal(new int[] { 1, 3, 12, 0, 0 }, nums);
    }

    [Fact]
    public void MoveZeroes_AllZeros_Works()
    {
        var solution = new MoveZero_Solution();
        int[] nums = { 0, 0, 0 };
        
        solution.MoveZeroes(nums);
        
        Assert.Equal(new int[] { 0, 0, 0 }, nums);
    }

    [Fact]
    public void MoveZeroes_NoZeros_Works()
    {
        var solution = new MoveZero_Solution();
        int[] nums = { 1, 2, 3 };
        
        solution.MoveZeroes(nums);
        
        Assert.Equal(new int[] { 1, 2, 3 }, nums);
    }

    [Fact]
    public void MoveZeroes_EmptyArray_Works()
    {
        var solution = new MoveZero_Solution();
        int[] nums = { };
        
        solution.MoveZeroes(nums);
        
        Assert.Equal(new int[] { }, nums);
    }
}
```

## 🎯 测试最佳实践

1. **命名规范**: `[方法名]_[场景]_[预期结果]`
2. **AAA 模式**: Arrange（准备）、Act（执行）、Assert（断言）
3. **独立性**: 每个测试应该独立，不依赖其他测试
4. **可重复**: 测试结果应该是确定的，不受外部因素影响
