# 2770. 达到末尾下标所需的最大跳跃次数

**难度：** 中等  
**标签：** 数组、动态规划  
**相关企业：** -

---

## 题目描述

给你一个下标从 0 开始、由 n 个整数组成的数组 `nums` 和一个整数 `target`。

你的初始位置在下标 0。在一步操作中，你可以从下标 `i` 跳跃到任意满足下述条件的下标 `j`：

- `0 <= i < j < n`
- `-target <= nums[j] - nums[i] <= target`

返回到达下标 `n - 1` 处所需的 **最大跳跃次数**。

如果无法到达下标 `n - 1`，返回 `-1`。

---

## 示例

### 示例 1

**输入：** `nums = [1,3,6,4,1,2], target = 2`  
**输出：** `3`

**解释：**要想以最大跳跃次数从下标 0 到下标 n - 1，可以按下述跳跃序列执行操作：

- 从下标 0 跳跃到下标 1。
- 从下标 1 跳跃到下标 3。
- 从下标 3 跳跃到下标 5。

可以证明，从 0 到 n - 1 的所有方案中，不存在比 3 步更长的跳跃序列。因此，答案是 3。

---

### 示例 2

**输入：** `nums = [1,3,6,4,1,2], target = 3`  
**输出：** `5`

**解释：**要想以最大跳跃次数从下标 0 到下标 n - 1，可以按下述跳跃序列执行操作：

- 从下标 0 跳跃到下标 1。
- 从下标 1 跳跃到下标 2。
- 从下标 2 跳跃到下标 3。
- 从下标 3 跳跃到下标 4。
- 从下标 4 跳跃到下标 5。

可以证明，从 0 到 n - 1 的所有方案中，不存在比 5 步更长的跳跃序列。因此，答案是 5。

### 示例 3

**解释：**可以证明不存在从 0 到 n - 1 的跳跃序列。因此，答案是 -1。

## 提示

- `2 <= nums.length == n <= 1000`
- `-10^9 <= nums[i] <= 10^9`
- `0 <= target <= 2 * 10^9`

---

## 解法思路

### 动态规划详解

#### 核心思路

这是一个典型的**最长路径问题**，由于只能向前跳跃（`i < j`），图结构是**有向无环图 (DAG)**，可以使用动态规划求解。

#### DP 定义

`dp[i]` 表示到达下标 `i` 的**最大跳跃次数**。

#### 状态转移方程

```
dp[i] = max(dp[j] + 1)  对于所有满足 |nums[i] - nums[j]| <= target 且 j < i 的 j
```

即：要到达位置 `i`，可以从前序任何位置 `j` 跳跃而来，取所有可能中的最大值。

#### 初始条件

- `dp[0] = 0`：起始位置不需要跳跃
- `dp[1..n-1] = -1`：初始化为 -1 表示不可达

#### 计算顺序

从小到大遍历 `i`，因为到达位置 `i` 只能从位置 `j < i` 跳跃而来。

#### 返回结果

- `dp[n-1]` 即为答案
- 如果为 -1，表示无法到达终点

---

### 算法图解

以 `nums = [1,3,6,4,1,2], target = 2` 为例：

```
下标:  0  1  2  3  4  5
值:    1  3  6  4  1  2
```

**跳跃关系分析：**

| 位置 | 可从前序哪些位置跳来 | 说明 |
|------|---------------------|------|
| 0 | - | 起点 |
| 1 | 0 | \|3-1\|=2 ≤ 2 |
| 2 | - | \|6-1\|=5, \|6-3\|=3 > 2 |
| 3 | 1 | \|4-3\|=1 ≤ 2 |
| 4 | 1, 3 | \|1-3\|=2, \|1-4\|=3 > 2 |
| 5 | 1, 3, 4 | \|2-1\|=1, \|2-3\|=1, \|2-4\|=2 |

**DP 计算过程：**

- `dp[0] = 0`（起点）
- `dp[1] = dp[0] + 1 = 1`（唯一选择）
- `dp[2] = -1`（无法到达）
- `dp[3] = dp[1] + 1 = 2`（唯一选择）
- `dp[4] = dp[1] + 1 = 2`（从位置 1 跳）
- `dp[5] = max(dp[3]+1, dp[4]+1) = max(3, 3) = 3`

**最优路径：** `0 → 1 → 3 → 5`（3步）或 `0 → 1 → 4 → 5`（3步）

---

### 复杂度分析

- **时间复杂度：** O(n²) - 双层循环遍历所有位置对
- **空间复杂度：** O(n) - dp 数组存储

---

## 代码实现

```csharp
public class Solution
{
    public int MaxJump(int[] nums, int target)
    {
        int n = nums.Length;
        int[] dp = new int[n];
        
        // 初始化为 -1，表示不可达
        for (int i = 1; i < n; i++)
            dp[i] = -1;
        
        // dp[0] = 0，起始位置
        for (int i = 1; i < n; i++)
        {
            for (int j = 0; j < i; j++)
            {
                if (dp[j] != -1 && Math.Abs(nums[i] - nums[j]) <= target)
                {
                    dp[i] = Math.Max(dp[i], dp[j] + 1);
                }
            }
        }
        
        return dp[n - 1];
    }
}
```
