# 300. 最长递增子序列

**难度：** 中等  
**标签：** 动态规划、二分查找  
**相关企业：** -

---

## 题目描述

给你一个整数数组 `nums`，找到其中**最长严格递增子序列**的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

---

## 示例

### 示例 1

**输入：** `nums = [10,9,2,5,3,7,101,18]`  
**输出：** `4`

**解释：** 最长递增子序列是 `[2,3,7,101]`，因此长度为 4。

### 示例 2

**输入：** `nums = [0,1,0,3,2,3]`  
**输出：** `2`

### 示例 3

**输入：** `nums = [7,7,7,7,7,7,7]`  
**输出：** `1`

---

## 提示

- `1 <= nums.length <= 2500`
- `-10^4 <= nums[i] <= 10^4`

---

## 进阶

你能将算法的时间复杂度降低到 **O(n log n)** 吗？

---

## 解法思路

### 方法一：动态规划 O(n²)

定义 `dp[i]` 表示以 `nums[i]` 结尾的最长递增子序列长度。

**状态转移：** `dp[i] = max(dp[j]) + 1`，其中 `j < i` 且 `nums[j] < nums[i]`。

```
初始：所有 dp[i] = 1（每个元素自身构成长度为 1 的序列）
答案：max(dp)
```

### 方法二：贪心 + 二分查找 O(n log n)

维护一个单调递增数组 `tails`，`tails[i]` 表示**长度为 `i+1` 的递增子序列的最小末尾元素**。

遍历 `nums` 中每个数 `x`：

1. 如果 `x > tails` 的最后一个元素，直接追加到尾部（延长了最长子序列）。
2. 否则，在 `tails` 中找到**第一个 ≥ x** 的位置并用 `x` 替换它（让该长度的子序列末尾更小，更有利于后续扩展）。

**最终结果就是 `tails` 的长度。**

---

## 算法图解

以 `nums = [10,9,2,5,3,7,101,18]` 为例：

| 步骤 | 当前值 | tails | 操作 |
|------|--------|-------|------|
| 初始 | - | `[]` | - |
| 10 | 10 | `[10]` | 追加 |
| 9 | 9 | `[9]` | 替换 10 → 9 |
| 2 | 2 | `[2]` | 替换 9 → 2 |
| 5 | 5 | `[2, 5]` | 追加 |
| 3 | 3 | `[2, 3]` | 替换 5 → 3 |
| 7 | 7 | `[2, 3, 7]` | 追加 |
| 101 | 101 | `[2, 3, 7, 101]` | 追加 |
| 18 | 18 | `[2, 3, 7, 18]` | 替换 101 → 18 |

最终 `tails` 长度为 **4**，即答案。

---

## 复杂度分析

- **时间复杂度：** 
  - 动态规划：O(n²)，两层嵌套循环
  - 二分查找：O(n log n)，遍历 + 每次二分 O(log k)
- **空间复杂度：** O(n)，`tails` 或 `dp` 数组

---

## 代码实现

```csharp
public class Solution
{
    public int LengthOfLIS(int[] nums)
    {
        if (nums.Length == 0) return 0;
        
        List<int> tails = new List<int>();
        
        foreach (int x in nums)
        {
            // 二分查找第一个 >= x 的位置
            int left = 0, right = tails.Count;
            while (left < right)
            {
                int mid = left + (right - left) / 2;
                if (tails[mid] < x)
                    left = mid + 1;
                else
                    right = mid;
            }
            
            // 没找到则追加，否则替换
            if (left == tails.Count)
                tails.Add(x);
            else
                tails[left] = x;
        }
        
        return tails.Count;
    }
}
```
