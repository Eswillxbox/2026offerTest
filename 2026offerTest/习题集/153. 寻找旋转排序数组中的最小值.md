# 153. 寻找旋转排序数组中的最小值

**难度：** 中等  
**标签：** 二分查找、数组  
**相关企业：** -

---

## 题目描述

已知一个长度为 `n` 的数组，预先按照升序排列，经由 **1 到 n 次旋转**后，得到输入数组。例如，原数组 `nums = [0,1,2,4,5,6,7]` 变化后可能得到：

- 若旋转 4 次，则可以得到 `[4,5,6,7,0,1,2]`
- 若旋转 7 次，则可以得到 `[0,1,2,4,5,6,7]`

注意，数组 `[a[0], a[1], ..., a[n-1]]` **旋转一次** 的结果为数组 `[a[n-1], a[0], a[1], ..., a[n-2]]`。

给你一个元素值**互不相同**的数组 `nums`，它原来是一个升序排列的数组，并按上述情形进行了多次旋转。请你找出并返回数组中的**最小元素**。

你必须设计一个时间复杂度为 **O(log n)** 的算法解决此问题。

---

## 示例

### 示例 1

**输入：** `nums = [3,4,5,1,2]`  
**输出：** `1`

**解释：** 原数组为 `[1,2,3,4,5]`，旋转 3 次得到输入数组。

### 示例 2

**输入：** `nums = [4,5,6,7,0,1,2]`  
**输出：** `0`

**解释：** 原数组为 `[0,1,2,4,5,6,7]`，旋转 4 次得到输入数组。

### 示例 3

**输入：** `nums = [11,13,15,17]`  
**输出：** `11`

**解释：** 原数组为 `[11,13,15,17]`，旋转 4 次（即回到原位）得到输入数组。

---

## 提示

- `n == nums.length`
- `1 <= n <= 5000`
- `-5000 <= nums[i] <= 5000`
- `nums` 中的所有整数互不相同
- `nums` 原来是一个升序排序的数组，并进行了 1 至 n 次旋转

---

## 解法思路

### 二分查找 O(log n)

旋转后的数组有一个关键性质：**从最小值位置开始，右半段单调递增；从左半段取任意点与右端点比较，可判断最小值在哪一半。**

```
       [12, 14,  3,  5,  8, 10]
        ↑左半段↑   ↑右半段↑     ↑
              min         r

特征: nums[l] > nums[r] → 存在"断崖"，min在中间某处
```

**二分策略：**

| 条件 | 含义 | 移动 |
|------|------|------|
| `mid == l` | 已收缩到单元素 | `r = mid` |
| `nums[mid] < nums[l]` | mid 在右半段（较小），最小值在左边（含 mid） | `r = mid` |
| `nums[mid] >= nums[l]` | mid 在左半段（较大），最小值在右边 | `l = mid + 1` |

更简洁的二分写法——直接比较 `mid` 和 `r`：

| 条件 | 含义 | 移动 |
|------|------|------|
| `nums[mid] > nums[r]` | mid 在左半段，最小值在右侧 | `l = mid + 1` |
| `nums[mid] < nums[r]` | mid 在右半段，最小值就是 mid 或在其左侧 | `r = mid` |

最终 `l == r` 即为最小值位置。

---

## 算法图解

以 `nums = [4,5,6,7,0,1,2]` 为例：

```
初始: l=0, r=6

    步  区间          mid  nums[mid] vs nums[r]      决策
────  ────────────    ───  ───────────────────────    ────
  1    [4,5,6,7,0,1,2]   3       7 > 2 (l>r)         l = 4
  2             [0,1,2]   4       0 < 2 (l<r)         r = 4
  3                 [0]   4       l == r               结束

答案 = nums[4] = 0 ✓
```

---

## 复杂度分析

- **时间复杂度：** O(log n)，标准二分查找
- **空间复杂度：** O(1)，原地操作

---

## 代码实现

```csharp
public class Solution
{
    public int FindMin(int[] nums)
    {
        int l = 0, r = nums.Length - 1;

        while (l < r)
        {
            int mid = l + (r - l) / 2;
            if (nums[mid] > nums[r])
                l = mid + 1;      // min 在右半段
            else
                r = mid;          // min 在左侧（含 mid）
        }

        return nums[l];
    }
}
```
