# 2784. 检查数组是否是好的

**难度：** 简单  
**标签：** 哈希表、计数、排序  
**相关企业：** -

---

## 题目描述

给你一个整数数组 `nums`，如果它是数组 `base[n]` 的一个排列，我们称它是个 **好** 数组。

`base[n] = [1, 2, ..., n - 1, n, n]`（换句话说，它是一个长度为 `n + 1` 且包含 `1` 到 `n - 1` 恰好各一次、包含 `n` 两次的一个数组）。比方说，`base[1] = [1, 1]`，`base[3] = [1, 2, 3, 3]`。

如果数组是一个好数组，请你返回 `true`，否则返回 `false`。

注意：数组的排列是这些数字按任意顺序排布后重新得到的数组。

---

## 示例

### 示例 1

**输入：** `nums = [2, 1, 3]`  
**输出：** `false`

**解释：** 最大元素是 3，对应的 `n = 3`。但 `base[3]` 有 4 个元素，而 `nums` 只有 3 个，无法构成 `base[3]` 的排列，返回 `false`。

### 示例 2

**输入：** `nums = [1, 3, 3, 2]`  
**输出：** `true`

**解释：** 最大元素是 3，对应的 `n = 3`。`nums` 是 `base[3] = [1, 2, 3, 3]` 的一个排列，返回 `true`。

### 示例 3

**输入：** `nums = [1, 1]`  
**输出：** `true`

**解释：** 最大元素是 1，对应的 `n = 1`。`nums` 是 `base[1] = [1, 1]` 的排列，返回 `true`。

### 示例 4

**输入：** `nums = [3, 4, 4, 1, 2, 1]`  
**输出：** `false`

**解释：** 最大元素是 4，对应的 `n = 4`。但 `base[4]` 有 5 个元素而 `nums` 有 6 个元素，返回 `false`。

---

## 提示

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 200`

---

## 解法思路

### 哈希表判重

判断一个数组是否为 `base[n]` 的排列，需要同时满足三个条件：

| 条件 | 含义 |
|------|------|
| `max(nums) + 1 == nums.Length` | 长度与最大值匹配 |
| `HashSet.Count == max` | 去重后剩 `n` 个不同值，说明恰好有一个值出现两次 |
| 非最大值的重复不存在 | 重复的那个必须是 `n` 本身 |

前两个条件容易想到，但容易忽略第三个。反例 `[5, 7, 3, 1, 5, 2, 6, 4]`：`max=7, len=8, set.size=7` 全部通过，但实际上重复的是 5 而非 7。

所以需要在遍历中额外记录：**一旦发现非最大值的重复，直接返回 `false`**。

---

## 算法图解

以 `nums = [5, 7, 3, 1, 5, 2, 6, 4]` 为例：

```
Step 1: 找出 max = 7
Step 2: 遍历验证
  5 → add       {5}
  7 → add       {5, 7}
  3 → add       {5, 7, 3}
  1 → add       {5, 7, 3, 1}
  5 → 已存在，5 < 7 → return false  ← 命中！
```

以 `nums = [1, 3, 3, 2]` 为例：

```
Step 1: 找出 max = 3
Step 2: 遍历验证
  1 → add       {1}
  3 → add       {1, 3}
  3 → 已存在，3 == 3 → 跳过
  2 → add       {1, 3, 2}
Step 3: 最终检查
  len(4) == max(3) + 1 ✓
  set.size(3) == max(3) ✓
→ true ✓
```

---

## 复杂度分析

- **时间复杂度：** O(n)，两遍遍历
- **空间复杂度：** O(n)，HashSet 存储不同元素

---

## 代码实现

```csharp
public class Solution
{
    public bool IsArrayGood(int[] nums)
    {
        // Step 1: 找最大值 n
        int n = 0;
        foreach (int x in nums)
            n = Math.Max(n, x);

        var seen = new HashSet<int>();
        // Step 2: 遍历验证
        foreach (int x in nums)
        {
            if (!seen.Add(x))         // 发现重复
                if (x < n) return false; // 非最大值重复，不是 base[n]
        }

        // Step 3: 长度和去重数量校验
        return nums.Length == n + 1 && seen.Count == n;
    }
}
```
