# Q2. 拼车

**难度：** 中等  
**标签：** 数组、排序、模拟、差分数组  
**相关企业：** Amazon、Google、Facebook

---

## 题目描述

车上最初有 `capacity` 个空座位。车 **只能** 向一个方向行驶（也就是说，不允许掉头或改变方向）

给定整数 `capacity` 和一个数组 `trips`，`trips[i] = [numPassengersi, fromi, toi]` 表示第 `i` 次旅行有 `numPassengersi` 乘客，接他们和放他们的位置分别是 `fromi` 和 `toi`。这些位置是从汽车的初始位置向东的公里数。

当且仅当你可以在所有给定的行程中接送所有乘客时，返回 `true`，否则请返回 `false`。

---

## 示例

### 示例 1

**输入：** `trips = [[2,1,5],[3,3,7]], capacity = 4`  
**输出：** `false`

**解释：** 在位置 3 时，车上已有 2 人（从1到5）+ 新上车 3 人 = 5 人 > 4 个座位。

---

### 示例 2

**输入：** `trips = [[2,1,5],[3,3,7]], capacity = 5`  
**输出：** `true`

**解释：** 在任何时刻，车上人数都未超过 5 人。

---

### 示例 3

**输入：** `trips = [[2,1,5],[3,5,7]], capacity = 3`  
**输出：** `true`

**解释：** 
- 位置 1-4：2 人（第一趟）
- 位置 5：第一趟下车，第二趟上车，共 3 人
- 位置 6-7：3 人

---

### 示例 4

**输入：** `trips = [[3,2,7],[3,7,9],[8,3,9]], capacity = 11`  
**输出：** `true`

**解释：** 
- 位置 2-6：3 人
- 位置 7-8：3+3=6 人
- 位置 9：全部下车

---

## 提示

- `1 <= trips.length <= 1000`
- `trips[i].length == 3`
- `1 <= numPassengersi <= 100`
- `0 <= fromi < toi <= 1000`
- `1 <= capacity <= 10^5`

---

## 解法思路

### 差分数组 / 桶计数

由于下车位置是**到达即下车**（即 `to` 位置乘客已经离开），我们可以用桶计数的方式：

1. 创建一个数组 `count[1001]` 记录每个位置的乘客变化
2. `count[from] += numPassengers`（上车）
3. `count[to] -= numPassengers`（下车）
4. 遍历数组，累加得到每个位置的实际乘客数，检查是否超过容量

#### 原理

例如 `trips = [[2,1,5],[3,3,7]]`：

| 位置 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|------|---|---|---|---|---|---|---|---|
| 变化 | 0 | +2 | 0 | +3 | 0 | -2 | 0 | -3 |
| 累计 | 0 | 2 | 2 | 5 | 5 | 3 | 3 | 0 |

### 复杂度

- **时间复杂度：** O(n + m)，其中 n 是 trip 数量，m 是站点范围（1001）
- **空间复杂度：** O(m)

---

## 代码实现

```csharp
public class Solution
{
    public bool CarPooling(int[][] trips, int capacity)
    {
        int[] count = new int[1001];
        
        foreach (var trip in trips)
        {
            int numPassengers = trip[0];
            int from = trip[1];
            int to = trip[2];
            
            count[from] += numPassengers;
            count[to] -= numPassengers;
        }
        
        int current = 0;
        for (int i = 0; i <= 1000; i++)
        {
            current += count[i];
            if (current > capacity)
                return false;
        }
        
        return true;
    }
}
```

## 进阶解法：排序 + 优先队列

如果站点范围很大（比如 10^9），可以用排序 + 优先队列：

1. 将所有上车/下车事件排序
2. 用优先队列按下车位置排序
3. 遍历每个站点，先处理下车，再处理上车

时间复杂度：O(n log n)
