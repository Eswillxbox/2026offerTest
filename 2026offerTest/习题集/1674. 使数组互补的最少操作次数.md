# 1674. 使数组互补的最少操作次数

**难度：** 中等  
**标签：** 差分标记、前缀和  
**相关企业：** -

---

## 题目描述

给你一个长度为 **偶数** `n` 的整数数组 `nums` 和一个整数 `limit`。每一次操作，你可以将 `nums` 中的任何整数替换为 `1` 到 `limit` 之间的另一个整数。

如果对于所有下标 `i`（下标从 0 开始），`nums[i] + nums[n - 1 - i]` 都等于同一个数，则数组 `nums` 是**互补**的。例如，数组 `[1,2,3,4]` 是互补的，因为对于所有下标 `i`，`nums[i] + nums[n - 1 - i] = 5`。

返回使数组互补的**最少**操作次数。

---

## 示例

### 示例 1

**输入：** `nums = [1,2,4,3], limit = 4`  
**输出：** `1`

**解释：** 经过 1 次操作，可以将数组变成 `[1,2,2,3]`：

```
nums[0] + nums[3] = 1 + 3 = 4
nums[1] + nums[2] = 2 + 2 = 4
```

每个对称对的和都为 4，所以数组互补。

### 示例 2

**输入：** `nums = [1,2,2,1], limit = 2`  
**输出：** `2`

**解释：** 经过 2 次操作，可将数组变成 `[2,2,2,2]`。不能将任何数字改为 3，因为 `3 > limit`。

### 示例 3

**输入：** `nums = [1,2,1,2], limit = 2`  
**输出：** `0`

**解释：** 已经互补（每对之和都是 3）。

---

## 提示

- `n == nums.length`
- `2 <= n <= 10^5`
- `1 <= nums[i] <= limit <= 10^5`
- `n` 是偶数

---

## 解法思路

### 差分标记 + 前缀和

枚举最终对称对的和目标值 `S`（范围 `[2, 2 * limit]`），计算让所有对都满足 `nums[i] + nums[n-1-i] = S` 所需的操作次数。

对每一对 `(a, b)`（令 `low = min(a,b)`，`high = max(a,b)`）：

| 目标和 S | 需要几次操作 | 原因 |
|----------|-------------|------|
| `S = a + b` | **0** | 已经满足 |
| `S ∈ [low + 1, high + limit]` 且 `S ≠ a + b` | **1** | 改一个小值即可（如把小的改成 `S - high`） |
| 其余情况 | **2** | 两个都要改（如全部改成 1 和 `S-1`） |

**算法步骤：**

1. 以差分数组记录修正量，每个 pair 默认贡献 2 次操作。
   - 实际代价 = `2 * (n/2) + prefixSum(diff[2..s])`
2. 对每对 `(a, b)`：
   - `diff[low+1]--`, `diff[high+limit+1]++` → `[low+1, high+limit]` 内从 2-op 降为 1-op
   - `diff[sum]--`, `diff[sum+1]++` → `S=sum` 时再降为 0-op
3. 求前缀和得到每个 `S` 的实际代价，取最小值。

---

## 算法图解

以 `nums = [1,2,4,3], limit = 4` 为例，有两对：`(1,3)` 和 `(2,4)`。基础 cost = `2 * 2 = 4`。

**第一对 `(1,3)`**，`low=1, high=3, sum=4, high+limit=7`：

```
diff[2]--,   diff[8]++,     // [2,7] 区间减 1
diff[4]--,   diff[5]++      // S=4 处再减 1
```

Diff 变化：{2:−1, 4:−1, 5:+1, 8:+1}

**第二对 `(2,4)`**，`low=2, high=4, sum=6, high+limit=8`：

```
diff[3]--,   diff[9]++,     // [3,8] 区间减 1
diff[6]--,   diff[7]++      // S=6 处再减 1
```

Diff 变化：{3:−1, 6:−1, 7:+1, 9:+1}

**合并所有 diff 并求前缀和**：

| S | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|
| diff[s] | −1 | −1 | −1 | +1 | −1 | +1 | +1 |
| prefixSum | −1 | −2 | −3 | −2 | −3 | −2 | −1 |
| cost=4+prefix | **3** | **2** | **1** | **2** | **1** | **2** | **3** |

最小值为 **1** ✓（目标值 S=4 或 S=6）。

---

## 复杂度分析

- **时间复杂度：** O(n + limit)，遍历所有对 O(n) + 遍历目标值 O(limit)
- **空间复杂度：** O(limit)，差分数组大小

---

## 代码实现

```csharp
public class Solution
{
    public int MinMoves(int[] nums, int limit)
    {
        int n = nums.Length;
        int[] diff = new int[2 * limit + 2];

        for (int i = 0; i < n / 2; i++)
        {
            int a = nums[i], b = nums[n - 1 - i];
            int low = Math.Min(a, b);
            int high = Math.Max(a, b);
            int sum = a + b;

            // 默认从 2 次起，到 high+1 结束（超出 min(1,x)+max(2,x) 范围）
            diff[2]++;
            diff[high + 1]++;

            // 在 [low+1, high+limit] 范围内只需 1 次操作
            diff[low + 1]--;
            diff[high + limit + 1]++;

            // 在 S = sum 时降为 0 次操作
            diff[sum]--;
            diff[sum + 1]++;
        }

        int ans = int.MaxValue;
        int current = 0;
        for (int s = 2; s <= 2 * limit; s++)
        {
            current += diff[s];
            if (current < ans) ans = current;
        }

        return ans;
    }
}
```
