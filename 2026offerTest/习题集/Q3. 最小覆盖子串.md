# Q3. 最小覆盖子串

**难度：** 困难  
**标签：** 字符串、滑动窗口  
**相关企业：** Amazon、Facebook、Microsoft

---

## 题目描述

给定两个字符串 `s` 和 `t`，长度分别是 `m` 和 `n`，返回 `s` 中的 **最短窗口** 子串，使得该子串包含 `t` 中的每一个字符（包括重复字符）。如果没有这样的子串，返回空字符串 `""`。

测试用例保证答案唯一。

---

## 示例

### 示例 1

**输入：** `s = "ADOBECODEBANC", t = "ABC"`  
**输出：** `"BANC"`

**解释：** 最小覆盖子串 `"BANC"` 包含来自字符串 `t` 的 `'A'`、`'B'` 和 `'C'`。

---

### 示例 2

**输入：** `s = "a", t = "a"`  
**输出：** `"a"`

**解释：** 整个字符串 `s` 是最小覆盖子串。

---

### 示例 3

**输入：** `s = "a", t = "aa"`  
**输出：** `""`

**解释：** `t` 中两个字符 `'a'` 均应包含在 `s` 的子串中，因此没有符合条件的子字符串，返回空字符串。

---

## 提示

- `m == s.length`
- `n == t.length`
- `1 <= m, n <= 10^5`
- `s` 和 `t` 由英文字母组成

---

## 解法思路

### 滑动窗口

使用双指针维护一个滑动窗口：

1. **扩展右边界**：直到窗口包含 `t` 的所有字符
2. **收缩左边界**：在满足条件的前提下尽可能缩小窗口
3. **记录最优解**：每次满足条件时更新最短子串

#### 关键点

- 使用哈希表记录 `t` 中每个字符的需求数量
- 使用哈希表记录当前窗口中每个字符的实际数量
- 当窗口满足条件时，尝试收缩左边界

---

## 进阶

你能设计一个在 O(m + n) 时间内解决此问题的算法吗？

## 代码实现

```csharp
public class Solution
{
    public string MinWindow(string s, string t)
    {
        if (string.IsNullOrEmpty(s) || string.IsNullOrEmpty(t) || s.Length < t.Length)
            return "";
        
        // 记录 t 中每个字符的需求量
        Dictionary<char, int> need = new Dictionary<char, int>();
        foreach (char c in t)
        {
            need[c] = need.GetValueOrDefault(c, 0) + 1;
        }
        
        int required = need.Count;  // 需要满足的字符种类数
        int formed = 0;             // 当前窗口已满足的字符种类数
        
        // 记录窗口中每个字符的数量
        Dictionary<char, int> window = new Dictionary<char, int>();
        
        int left = 0, right = 0;
        int ansLength = int.MaxValue;
        int ansLeft = 0, ansRight = 0;
        
        while (right < s.Length)
        {
            char c = s[right];
            window[c] = window.GetValueOrDefault(c, 0) + 1;
            
            // 如果当前字符在 t 中，且数量刚好满足需求
            if (need.ContainsKey(c) && window[c] == need[c])
            {
                formed++;
            }
            
            // 尝试收缩窗口
            while (left <= right && formed == required)
            {
                c = s[left];
                
                // 更新最优解
                if (right - left + 1 < ansLength)
                {
                    ansLength = right - left + 1;
                    ansLeft = left;
                    ansRight = right;
                }
                
                // 收缩左边界
                window[c]--;
                if (need.ContainsKey(c) && window[c] < need[c])
                {
                    formed--;
                }
                
                left++;
            }
            
            right++;
        }
        
        return ansLength == int.MaxValue ? "" : s.Substring(ansLeft, ansLength);
    }
}
```

---

## 复杂度分析

- **时间复杂度：** O(m + n) - 每个字符最多被访问两次（左右指针各一次）
- **空间复杂度：** O(m + n) - 哈希表存储字符计数
