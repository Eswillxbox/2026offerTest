## 📝 学习方法

1. **理解题意** - 仔细阅读题目，明确输入输出
2. **思考思路** - 先自己想解法，不要急着看答案
3. **实现代码** - 独立编写代码，注意边界条件
4. **分析复杂度** - 计算时间和空间复杂度
5. **总结归纳** - 记录解题模板和技巧
6. **定期复习** - 每周回顾做过的题目

## 💡 常用算法模板

### 二分查找模板
```csharp
int left = 0, right = nums.Length - 1;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (nums[mid] == target) return mid;
    else if (nums[mid] > target) right = mid - 1;
    else left = mid + 1;
}
```

### 双指针模板
```csharp
int slow = 0;
for (int fast = 0; fast < nums.Length; fast++) {
    if (condition) {
        // 操作 slow
        slow++;
    }
}
```

### 动态规划模板
```csharp
// 1. 定义状态
dp[i] = ...

// 2. 初始化
dp[0] = base_case;

// 3. 状态转移
for (int i = 1; i <= n; i++) {
    dp[i] = transition(dp[i-1], ...);
}

// 4. 返回结果
return dp[n];
```
