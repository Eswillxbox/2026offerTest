# 007. 知道秘密的人数 (Number of People Aware of a Secret)

**难度**: 中等  
**标签**: 动态规划, 滑动窗口

---

## 📝 题目描述

在第 `1` 天，有一个人发现了一个秘密。

给你一个整数 `delay`，表示每个人会在发现秘密后的 `delay` 天之后，每天给一个新的人分享这个秘密。同时给你一个整数 `forget`，表示每个人在发现秘密 `forget` 天之后会忘记这个秘密。一个人 **不能** 在忘记秘密的那一天或之后分享秘密。

给你整数 `n`，请你返回在第 `n` 天结束时，知道秘密的人数。由于答案可能很大，请返回对 `10^9 + 7` 取余的结果。

---

## 💡 示例

### 示例 1
```
输入: n = 6, delay = 2, forget = 4
输出: 5
```

### 示例 2
```
输入: n = 4, delay = 1, forget = 3
输出: 6
```

---

## 🎯 解题思路

**核心思想**: 动态规划 + 滑动窗口

**状态定义**: 
- `dp[i]` 表示第 `i` 天新知道秘密的人数

**关键观察**:
- 第 `i` 天能分享秘密的人是那些在 `[i-forget+1, i-delay]` 范围内知道秘密的人
- 使用变量 `sharing` 维护当前可以分享秘密的人数

**步骤**:
1. 初始化 `dp[1] = 1`
2. 遍历每一天，更新 `sharing`：
   - 加上第 `i-delay` 天新知道的人（他们可以开始分享了）
   - 减去第 `i-forget` 天新知道的人（他们已经忘记了）
3. `dp[i] = sharing`
4. 最后统计第 `n` 天时还未忘记秘密的总人数

---

## 📊 复杂度分析

- **时间复杂度**: O(n) - 遍历 n 天
- **空间复杂度**: O(n) 或 O(forget) - 可使用滚动数组优化

---

## 🔑 关键点

- 理解 delay 和 forget 的含义
- 使用滑动窗口维护可以分享秘密的人数
- 注意取模运算，避免负数
