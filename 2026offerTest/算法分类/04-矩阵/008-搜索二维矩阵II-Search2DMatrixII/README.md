# 008. 搜索二维矩阵 II (Search a 2D Matrix II)

**难度**: 中等  
**标签**: 矩阵, 二分查找, 双指针

---

## 📝 题目描述

编写一个高效的算法来搜索 `m x n` 矩阵 `matrix` 中的一个目标值 `target`。该矩阵具有以下特性：

- 每行的元素从左到右升序排列
- 每列的元素从上到下升序排列

---

## 💡 示例

### 示例 1
```
输入: 
matrix = [
  [1,   4,  7, 11, 15],
  [2,   5,  8, 12, 19],
  [3,   6,  9, 16, 22],
  [10, 13, 14, 17, 24],
  [18, 21, 23, 26, 30]
], 
target = 5

输出: true
```

### 示例 2
```
输入: 
matrix = [
  [1,   4,  7, 11, 15],
  [2,   5,  8, 12, 19],
  [3,   6,  9, 16, 22],
  [10, 13, 14, 17, 24],
  [18, 21, 23, 26, 30]
], 
target = 20

输出: false
```

---

## 🎯 解题思路

**核心思想**: 从右上角（或左下角）开始搜索，利用矩阵的有序性

**为什么选择右上角？**
- 右上角的元素是当前行的最大值，当前列的最小值
- 如果 `target < matrix[row][col]`，说明 target 不可能在当前列，`col--`
- 如果 `target > matrix[row][col]`，说明 target 不可能在当前行，`row++`

**步骤**:
1. 从右上角开始 (`row = 0`, `col = cols - 1`)
2. 比较当前元素与 target：
   - 相等：返回 true
   - 当前值太大：向左移动 (`col--`)
   - 当前值太小：向下移动 (`row++`)
3. 越界则返回 false

---

## 📊 复杂度分析

- **时间复杂度**: O(m + n) - 最多走 m+n 步
- **空间复杂度**: O(1) - 只使用常数额外空间

---

## 🔑 关键点

- 起点必须是右上角或左下角（不能是左上角或右下角）
- 每次排除一行或一列，效率很高
- 这种搜索方式被称为"步进搜索"
